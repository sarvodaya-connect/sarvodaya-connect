# Sarvodaya Connect Mobile Application

The cross-platform mobile application for the Sarvodaya Connect platform.

## Technology

- Flutter
- Dart
- Riverpod
- GoRouter
- Dio
- Flutter Secure Storage
- Material 3

## Target Platforms

- Android
- iOS

## Development

The Flutter application will be initialized in a separate Jira task and pull request.

Do not commit passwords, access tokens, client information, or local environment files to this directory.
